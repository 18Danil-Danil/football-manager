# Football Manager

Веб- и desktop-менеджер футбольного клуба. Проект развивается на TypeScript, React и Vite; настольная сборка будет добавлена через Tauri.

## Быстрый запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
```

## Текущий статус

**Версия 0.1.0 — pre-alpha.** Сейчас доступен стартовый интерфейс клуба: обзор, финансовые и спортивные показатели, ближайший матч, таблица лиги и список игроков. Данные демонстрационные.

## План разработки

1. Игровая модель клуба, игрока и сезона.
2. Редактирование состава и тактических схем.
3. Генератор матчей и симуляция.
4. Календарь и турнирные таблицы.
5. Трансферы, контракты и зарплаты.
6. Финансы, стадион и развитие инфраструктуры.
7. Сохранение и загрузка карьеры.
8. Desktop-сборка на Tauri.

## Архитектурный принцип

Игровая логика будет вынесена в независимое TypeScript-ядро. React отвечает за интерфейс, а веб- и desktop-версии используют одну модель данных и правила симуляции.
